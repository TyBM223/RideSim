# Concrete, fully-resolved dependency lock.
#
# pyproject.toml declares ABSTRACT dependencies -- the ranges this code is
# compatible with. This file declares CONCRETE ones -- the exact versions the
# test suite was last verified green against, including transitive packages we
# never import directly. That split is what makes a build reproducible: two
# machines installing from this file get byte-identical dependency trees, so
# "works on my machine" cannot be a version-skew problem.
#
# Regenerate after changing dependencies:
#     ./venv/bin/pip freeze --exclude-editable > requirements.txt
#
# Install (after creating a venv):
#     pip install -r requirements.txt && pip install -e . --no-deps
